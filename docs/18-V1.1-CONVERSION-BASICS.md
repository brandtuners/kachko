# V1.1 Conversion Basics

V1.1 turns public-page traffic into creator-owned contacts. Apply migration `20261002010000_conversion_basics` before starting the updated API.

## Product surface

- The editor starts with goals for enquiries, WhatsApp chats, and subscriptions, while keeping the direct block library available.
- Contact forms and signup forms can be created and edited at `/dashboard/forms`.
- Contacts can be searched, filtered, reviewed, tagged, annotated, and exported at `/dashboard/audience`.
- Public pages render only known block types. Form blocks reference a stored `Form`; form logic is not stored inside arbitrary block JSON.
- Analytics records form views, form submissions, new leads, subscriptions, and WhatsApp clicks. The dashboard exposes the conversion funnel for the active page.

## API surface

Authenticated creator endpoints:

```text
GET|POST       /api/v1/pages/:pageId/forms
GET|PATCH|DELETE /api/v1/forms/:formId
POST           /api/v1/forms/:formId/fields
PATCH|DELETE   /api/v1/forms/:formId/fields/:fieldId
POST           /api/v1/forms/:formId/fields/reorder

GET            /api/v1/audience/contacts
GET|PATCH      /api/v1/audience/contacts/:contactId
POST           /api/v1/audience/contacts/:contactId/notes
POST           /api/v1/audience/contacts/:contactId/tags
DELETE         /api/v1/audience/contacts/:contactId/tags/:tagId
GET            /api/v1/audience/export

GET            /api/v1/analytics/pages/:pageId/conversion-funnel
```

Audience query parameters are `status`, `tag`, `search`, `source`, `from`, `to`, `page`, and `limit`.

Public endpoint:

```text
POST /api/v1/public/forms/:formId/submissions
```

The public endpoint accepts only fields defined on an active form referenced by a visible block on a published, active creator page.

## Ownership and data behavior

- Every creator read and mutation is scoped through the authenticated user to the owned page or contact. A different creator receives `404`, avoiding resource disclosure.
- Email is trimmed and lowercased. Phone fields require E.164 format. Contacts deduplicate only within one creator by normalized email or phone; repeat submissions remain visible on the same contact.
- A subscription records marketing consent. A later opt-in upgrades consent but a later non-opt-in does not erase it.
- CSV cells beginning with spreadsheet formula characters are prefixed safely.
- Deleting a form referenced by a page block returns `409`; remove its block first.

## Abuse protection

Public submissions have per-IP Redis rate limiting, a honeypot, strict request/field schemas, a 20-field and 20,000-character aggregate limit, HTML/control-character stripping, URL/spam heuristics, and hashed IP storage. CAPTCHA remains an optional escalation rather than a default dependency.
